Relive

把喜欢的瞬间，变成 Live Photo。版本 1.0 · Mac Apple Silicon

制作一张实况图

  1. 拖入素材，或点击「导入素材」。支持 SVG、GIF、MOV、MP4、MPV、MKV、WebM、AVI 等 FFmpeg 可解码的视频，以及 PNG/JPEG 等静态图片。
  2. 播放预览，拖动时间轴定位；使用左右箭头逐帧切换。点击「设为封面」，或输入从 1 开始的帧号并确认。「首帧」会选择第 1 帧。
  3. 默认导出完整素材。可设置片段的开始和结束时间；封面必须位于所选片段内。长边上限可选 1080 或 1920 像素，始终保持原比例。
  4. 选择输出文件夹和是否保留声音，点击「导出 Live Photo」。生成的 .pvt 包内含配对 JPEG、MOV、实况封面时间标记，导出前会由 Apple Photos 框架验证。

在 iPhone 上发布小红书

  1. 点击「导入照片」，或双击导出的 .pvt，将其导入 Mac「照片」App。
  2. 通过同一 Apple 账户的 iCloud 照片同步到 iPhone；也可以在 Mac「照片」App 内使用隔空投送分享这张实况照片。请保留实况信息。
  3. 在 iPhone「照片」中确认出现 LIVE 标识，长按可以播放。
  4. 打开 iPhone 小红书 App，从相册选择该实况照片，并在发布界面保留实况效果。具体界面及可用能力随小红书版本变化。

Relive 导出的是 Apple Live Photo。请先进入 iPhone 相册，再从小红书选择；将单独的 JPG、MOV 或 .pvt 上传到网页不会等同于上传实况照片。软件已验证 Mac 系统识别；当前尚未在你的 iPhone 账号实际发布测试。

SVG 与透明背景

SVG 支持 SMIL 和 CSS 动画；导入前可以设置录制时长（1–30 秒）及白色/黑色背景。静态 SVG 会生成静态画面的实况片段，不会自动添加运动。为让文件在离线环境中可靠渲染，SVG 的外链资源与 JavaScript 不执行；请使用 UTF-8 普通 SVG，并将图片和字体内嵌；DTD 和实体定义不接受。视频、GIF 的透明区域也会在导入时铺为所选背景。素材预览在本地转为 H.264，帧率最高 60 fps、长边最高 1920 像素。

文件与隐私

全部转换在本机执行，不上传素材。原文件保持不变。导出重名文件会自动编号，避免覆盖。素材列表为当前编辑会话，关闭软件后清除临时预览；已导出的文件保留。

安装与维护

此版本适用于 Apple Silicon Mac，macOS 13 或更新。软件内已包含 FFmpeg、ffprobe 和所需库，无需安装 Python 或命令行工具。本地包采用临时签名，未进行 Apple 公证。第三方许可证随软件附带，可从「帮助 → 第三方许可」查看。
