Relive

把喜欢的瞬间，变成 Live Photo。版本 1.1.0 · Apple Silicon / Intel Mac · Windows x64

安装与打开

Mac 版适用于 macOS 13 或更新：选择对应芯片的 DMG，将 Relive 拖入「应用程序」。Windows 版适用于 Windows 10 / 11 x64：运行安装程序，或解压便携 ZIP 后打开 Relive.exe。三平台均内置 FFmpeg、ffprobe 及所需运行时，无需额外安装 Python、Node.js 或命令行工具。

Mac 包采用临时签名，未进行 Apple 公证；Windows 包未正式代码签名。第三方许可证和构建来源随软件附带。

制作一张实况图

  1. 拖入素材，或点击「导入素材」。支持 SVG、GIF、MOV、MP4、MPV，以及其他 FFmpeg 可解码的视频和静态图片。
  2. 播放预览，拖动时间线定位；使用左右箭头逐帧切换。点击「设为封面」，或输入从 1 开始的帧号并确认。「使用首帧」选择第 1 帧。
  3. 默认导出完整素材。Mac 使用开始 / 结束时间裁切；Windows 使用开始 / 结束帧裁切，两端帧均保留。封面须位于片段内。最长边可选 1080 或 1920 像素，保持原比例。
  4. 选择输出文件夹和是否保留声音，点击「导出 Live Photo」。生成 .pvt 包，内含配对 JPEG、MOV 和实况封面时间标记。Mac 原生版通过 Apple Photos 框架识别校验；Windows 版检查配对结构、媒体和时间标记。

通过 Mac 传到 iPhone

  1. 点击「导入照片」，或双击导出的 .pvt，导入 Mac「照片」App。
  2. 通过同一 Apple 账户的 iCloud 照片同步到 iPhone，或从 Mac「照片」App 内使用隔空投送分享，并保留实况信息。
  3. 在 iPhone「照片」中确认 LIVE 标识，长按可以播放。

仅用 Windows 传到 iPhone

使用支持 Live Photo 配对导入的 iOS 相册工具，将 .pvt 包内的配对 JPEG 和 MOV 一起导入 iPhone 系统相册。也可以将 .pvt 交由 Mac「照片」导入，再按上面的步骤传到 iPhone。单独保存 JPEG 不会自动成为实况照片。

在小红书发布

先在 iPhone「照片」确认 LIVE 并可播放，再打开小红书，从相册选择这张实况照片并保留实况效果。具体界面和识别能力随小红书版本变化。

Relive 已通过原生 Intel CI 自测、Windows 完整转换与打包后烟雾测试。iPhone 小红书实际发布尚未测试。直接上传 JPEG、MOV 或 .pvt 不会等同于从 iPhone 相册发布 Live Photo。

SVG 与透明背景

SVG 支持 SMIL 和 CSS 动画；导入前可设置录制时长（1–30 秒）及白色 / 黑色背景。静态 SVG 保持静态，不会自动添加运动。SVG 外链与脚本不执行，DTD 和实体定义不接受；请使用 UTF-8，并内嵌图片和字体。视频、GIF 的透明区域铺为所选背景。素材预览在本地转为 H.264，帧率最高 60 fps、最长边最高 1920 像素。

文件与隐私

全部转换在本机执行，不上传素材。原文件保持不变，重名输出自动编号。素材列表仅保留当前会话，关闭软件后清理临时预览，已导出的作品保留。

源码与构建记录保存在 Relive 私有 GitHub 仓库，需要仓库访问权限。
