Relive

把喜欢的瞬间，变成实况、视频与动图。版本 1.3.0 · Apple Silicon / Intel Mac · Windows x64

安装与打开

Mac 版适用于 macOS 13 或更新：选择对应芯片的 DMG，将 Relive 拖入「应用程序」。Windows 版适用于 Windows 10 / 11 x64：运行安装程序，或解压便携 ZIP 后打开 Relive.exe。三平台均内置 FFmpeg、ffprobe、WebP 工具及所需运行时，无需额外安装 Python、Node.js 或命令行工具。

Mac 包采用临时签名，未进行 Apple 公证；Windows 包未正式代码签名。第三方许可证和构建来源随软件附带。

请使用 v1.3.0 安装包体验画面裁剪、画质档位和新增格式。

制作一张实况图

  1. 拖入素材，或点击「导入素材」。支持 SVG、GIF、MOV、MP4、MPV，以及其他 FFmpeg 可解码的视频和静态图片。
  2. 播放预览，拖动时间线定位；使用左右箭头逐帧切换。点击「设为封面」，或输入从 1 开始的帧号并确认。「使用首帧」选择第 1 帧。
  3. 默认导出完整素材。Mac 使用开始 / 结束时间裁切；Windows 使用开始 / 结束帧裁切，两端帧均保留。封面须位于片段内。按需裁剪画面并选择画质档位。
  4. 选择输出文件夹和是否保留声音，点击「导出 Live Photo」。生成 .pvt 包，内含配对 JPEG、MOV 和实况封面时间标记。Mac 原生版通过 Apple Photos 框架识别校验；Windows 版检查配对结构、媒体和时间标记。

画质与裁剪画面

画质可选原画质、高清（最长边 1920）、标准（最长边 1080）、省空间（最长边 720）。所有档位保持比例，不主动放大素材；后三档按最长边上限缩小。原画质通常保留原素材画布；裁剪画面后，以裁剪区域为导出画布，部分编码格式会将宽高调整为相邻的偶数。原画质仍需重新编码，不保证逐位无损、原始编码、HDR 色彩及元数据完全保留。

点击「裁剪画面」，在预览中拖动边缘或四角改变范围，拖动选区移动位置，或重置为完整画面。裁剪会应用于封面和所有视觉导出，并先于画质缩放执行；开始 / 结束时间仅控制片段时长，两者可分别调整。音频导出不使用画面裁剪。预览最长边最高 1920 像素，不决定原画质导出的像素尺寸。

导出视频、GIF 与音频

在「输出格式」中选择 MP4、MOV、MKV 或 WebM，即可将所选片段导出为普通视频；WebM 使用 VP9 视频及可选 Opus 音频。视频沿用画面裁剪和画质设置，有音轨时可选择保留声音。普通视频不携带 Live Photo 的实况配对信息，也不使用独立封面时间标记。

GIF 按片段顺序循环播放，不含声音，最高 30 fps。GIF 调色板最多 256 色，渐变和细节可能出现色带或抖动，文件可能比视频大。

MP3、WAV 用于提取有声音素材的所选片段。没有音轨时无法导出音频；封面和画面裁剪不参与音频输出。MP3 使用有损压缩；WAV 使用 PCM，通常占用更多空间。音频档位控制编码设置，不代表图片分辨率或原音轨逐位复制。

导出 WebP 动图

  1. 导入素材，在右侧「输出格式」选择 WebP 动图。
  2. 按需裁切片段、裁剪画面，并选择画质档位。WebP 保留原播放顺序，以片段首帧开始循环；不使用独立封面，也不含声音。
  3. 选择保存位置并导出。生成一个 .webp 文件，结果显示尺寸、实际时长和文件大小。点击「打开文件夹」取出文件。

最高 30 fps、无限循环。GIF 和 WebP 沿用素材导入时的白色 / 黑色背景，不保证保留原透明通道。单帧或完全静止的画面可能合并为静态 WebP，会在结果中标注。软件不自动将文件压到 10 MB，也不会为缩小体积而截短片段。

WebP 作为通用动图文件使用，不作为小红书发布方式推荐。制作小红书实况图请选 Live Photo，并按下面的流程导入 iPhone 系统相册。

通过 Mac 传到 iPhone

  1. 点击「导入照片」，或双击导出的 .pvt，导入 Mac「照片」App。
  2. 通过同一 Apple 账户的 iCloud 照片同步到 iPhone，或从 Mac「照片」App 内使用隔空投送分享，并保留实况信息。
  3. 在 iPhone「照片」中确认 LIVE 标识，长按可以播放。

仅用 Windows 传到 iPhone

使用支持 Live Photo 配对导入的 iOS 相册工具，将 .pvt 包内的配对 JPEG 和 MOV 一起导入 iPhone 系统相册。也可以将 .pvt 交由 Mac「照片」导入，再按上面的步骤传到 iPhone。单独保存 JPEG 不会自动成为实况照片。

在小红书发布 Live Photo

先在 iPhone「照片」确认 LIVE 并可播放，再打开小红书，从相册选择这张实况照片并保留实况效果。具体界面和识别能力随小红书版本变化。

1.2.0 已有原生 Intel CI 自测、Windows 完整转换与打包后烟雾测试的通过记录；这些记录不代表新增格式、画质和画面裁剪已经完成跨平台验证。iPhone 小红书实际发布尚未测试。直接上传 JPEG、MOV 或 .pvt 不会等同于从 iPhone 相册发布 Live Photo。

SVG 与透明背景

SVG 支持 SMIL 和 CSS 动画；导入前可设置录制时长（1–30 秒）及白色 / 黑色背景，原画质模式录制最长边上限为 4096。静态 SVG 保持静态，不会自动添加运动。SVG 外链与脚本不执行，DTD 和实体定义不接受；请使用 UTF-8，并内嵌图片和字体。视频、GIF 的透明区域铺为所选背景。素材预览在本地转为 H.264，帧率最高 60 fps、最长边最高 1920 像素。

文件与隐私

全部转换在本机执行，不上传素材。原文件保持不变，重名输出自动编号。素材列表仅保留当前会话，关闭软件后清理临时预览，已导出的作品保留。

源码与构建记录保存在 Relive 私有 GitHub 仓库，需要仓库访问权限。
